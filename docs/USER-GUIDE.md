# 使用指南

粘贴英文文章 → AI 智能分段 → 逐句语法分析与翻译 → 按原文顺序绘图 → 中英与结构图对照输出。

> 原流程为 n8n 工作流，现迁移为独立 Web 应用。双击 `start.bat` 即用。

---

## 功能

- **分段预览与纠错** — 默认修复 PDF 复制折行，保留可信段落；预览中可在句界换段、合并上一段、撤销。确认后才开始逐句分析。普通文本可选择“保留现有换行与段落”。
- **原文保真** — 保留 Mr./Mrs./Dr. 等称谓、短对话和无句号尾句；左栏始终基于完整段落渲染，未分析文字也不会被删除。
- **按原文顺序绘图** — 模型返回连续语法片段，程序核对原文区间、覆盖情况并排序；插入定语从句位于主句前后片段之间，各片段带序号。无效覆盖会提示重试，不生成缺词的图。
- **原文、译文与结构图三栏** — EPUB 保留原版书内排版，译文独立显示；直接拖动栏边界调整宽度，点击任一句可同步高亮译文并定位结构图。译文来自同一次句子分析，不额外请求翻译服务。缺少译文时明确标示，在线与离线共用布局。
- **每句独立画布** — 按图片实际比例自动调整画布高度：短图紧凑，纵向长图拉高；极长图限制为约两屏、最高 1800px。图片默认完整显示，不裁切；随栏宽/窗口变化重新适配。点击图后滚轮缩放、左键拖动；点击图外或按 Esc 恢复文章滚动。手动缩放状态会保留，角落提供缩放、100% 和整图适配按钮，离线 HTML 同样可用。
- **栏宽可调** — 底部滑杆调整“原文与译文”阅读区和图形区域的比例；阅读区内部默认英文与中文为 3:1。

- **智能分段** — AI 自动识别 PDF/复制文本中的假换行，按语义重排段落
- **逐句语法拆解** — DeepSeek 对每句话分析句型、主谓宾、从句、固定搭配，生成 PlantUML 思维导图
- **双屏阅读** — 原文与译文保留在主窗口，结构图可在独立大窗口显示；关闭大图窗口恢复三栏。
- **直接定位与联动** — 点击英文或译文一次直达对应语法图；预留未加载图像的画布高度，加载期间保持目标位置，快速切换以最后一次点击为准。手动滚动右栏解除定位，回到随图高亮。
- **实时时间预估** — 进度条显示已用时间、预估剩余时间、预估总时间
- **文件上传 + 粘贴** — 支持直接粘贴文本，或拖拽上传 `.txt` / `.pdf` / `.epub`
- **EPUB 小说导入** — 上传后从 EPUB 3 toc nav、EPUB 2 NCX、书内 HTML 目录或有结构依据的章标题提取目录，保留来源、层级和定位范围。文档元数据、署名、献词及内部文件名不自动当作章标题；不确定的标题单独列为“待核对”。未检出有效分章目录时，使用“打开阅读预览”查看书内材料；原书只有一个正文入口时明确说明。目录扫描先在本地完成；没有分章目录或只有整本正文入口时，上传后会自动调用已配置的 DeepSeek 接口生成 AI 阅读目录。已存在正常目录时保留原目录；目录解析异常时提示核对，不自动覆盖。
- **自动补建 AI 目录** — 无分章目录的 EPUB 上传后自动读取正文，只选择分节位置，小节用 Section 1、Section 2… 编号，不生成中文或英文的情节概括标题，并另存带目录的新版 EPUB。页面显示“AI 阅读目录”和下载入口；原文、图片及原始文件保留。首次生成会将书内文字发送到现有 DeepSeek API 并产生用量，同一文件在当前生成版本下再次上传或重启后可复用已保存结果。生成失败保留阅读预览与重试入口。EPUB2 写入 NCX/XHTML 目录，EPUB3 写入导航文档及兼容 NCX；分节位置由 AI 选择，Section 编号不代表原书章名；原书已有英文目录的标题和顺序原样保留。
- **多章合并分析** — 勾选多个目录条目后，点击“载入选中目录条目”，按目录顺序合并所选内容，再确认分析。改变勾选会使旧预览失效，避免误分析上一次载入的单章；直接点击标题则切换到单项。目录残缺、链接失效或多个来源冲突会提示核对，未列入目录的内容仍可通过阅读预览访问。
- **阅读区折叠** — 目录与分段预览可分别收起，底部“收起输入与预览”可一次收起上方区域；目录刷新保持现有折叠状态。
- **书籍与阅读进度恢复** — 原始 EPUB 保存在本地 `data/reader-session/`，刷新、后台重启和关闭重开后可恢复书籍、所选章节、分段修改、上次结果及阅读位置。分析逐句保存进度，中断后点击“继续分析”复用已保存句子。正在等待服务返回而尚未保存的一句可能需要重试。
- **最近阅读** — 展开页面顶部的「最近阅读」，每本 EPUB 有独立的阅读进度。切换前保存当前内容。点击旧书，在同一个标签页恢复它的章节、结果和分析断点。已有原书而缺少旧记录的条目显示「暂无阅读进度」。也可切回最近一份粘贴草稿。
- **固定入口与重复启动** — 启动器固定使用 `http://127.0.0.1:3456/`。再次双击桌面图标时复用当前服务，并将原阅读标签页切到前台；浏览器最小化时会恢复窗口。后台更新后原标签页自动重新连接并恢复阅读。无法切回页面或启动异常时显示提示，可按提示打开固定地址。
- **长结果恢复** — 全部原文、译文和句子入口会保留，结构图优先初始化当前阅读位置附近的部分；滚动或点击远处句子时再初始化对应图表。历史离线 HTML 自带保存时的脚本，不会随应用更新而自动改变。
- **逐书文字核对** — 每次导入重新对照源文件文字与可读内容。章号、章名、导语、正文、注释和书后材料进入核对。未列入阅读顺序的 HTML 另有阅读入口，无法确认完整性时明确报错。
- **短语译文** — 未继续拆分的语法节点显示“英文｜中文”；有子节点的部分继续在子节点显示对应译文。分句保护 `St. Petersburg`、`St. Peter’s`、`Mt. Everest` 等名称缩写。
- **EPUB 原版阅读** — 新生成的 EPUB 默认显示原版，保留章节标题、段落、斜体、插图、书内样式及字体，按阅读栏宽重新排版。点击英文句子可定位独立译文和结构图；多章合并与离线 HTML 同样支持。历史 HTML 未保存原版数据，需要重新导入 EPUB 并生成结果。

原版阅读隔离书内脚本与外部资源，只嵌入书内图片、字体和样式。导入前限制单个 CSS 为 2 MB、文本文件为 8 MB、图片/字体为 5 MB；全书解压文本累计 32 MB、累计文档节点 200000、嵌套深度 256、正文标题 1000 个、目录和候选合计 1600 个，最多检查 32 个不同来源与 4000 个来源条目。原版数据累计 64 MB，所选内容的原版导出数据最多 28 MB。超出时明确提示分册或减少所选材料。不同阅读器的字体设置和分页规则可能不同，原版视图采用连续阅读布局。
- **永久保存完整 HTML** — 每次完成后自动把“左栏文章 + 右栏句子拆解/思维导图 + 联动布局”写入 `outputs/`，关闭浏览器和服务后仍可直接打开

AI 目录版另存为 `outputs/ai-directory-v3-<文件摘要>.epub`，页面提供下载入口。缓存按原文件内容识别，不按文件名识别。旧 v2 缓存及重新上传的旧 AI 目录版会在本地更新为 Section 编号，不重新请求模型；旧文件保留。AI 目录当前处理上限为 100 万正文字符、8 个重叠窗口、128 个小节；图片书未接入 OCR，无法定位的超长单段会明确提示。小节长度按内容确定，并非严格等长。原始文件不被覆盖。

### 结果保存位置

每次处理成功都会生成一个独立文件：

```text
outputs/sentence-decomposition-YYYYMMDD-HHmmss.html
```

该 HTML 自包含样式、交互和 base64 图片，不依赖 `localhost`。关闭浏览器、关闭 CMD 窗口或重启电脑后，直接双击这个文件即可回看完整阅读结果。系统不会自动删除历史结果。

主页面自身已嵌入全部图片及画布交互，可单独复制、离线查看。兼容保留的 `<结果文件名>-diagram-<句子序号>.html` 独立图页不再占用主页面的按钮行；旧版 `output/` 文件保留，新的结果统一写入 `outputs/`。历史 HTML 不会自动改变；如另存画布版，复用原图即可，无须再次调用模型。

处理顺序：粘贴或上传 → 选择输入格式 → “整理分段并预览” → 检查或局部调整 → “确认分段并分析”。EPUB 小说则是：上传 `.epub` → 自动检查目录，缺少分章时生成并保存 AI 阅读目录 → 选择目录条目（生成失败或目录需核对时仍可打开阅读预览）→ 检查分段 → “确认分段并分析”；章节正文沿用原书段落（等同“保留现有换行与段落”），一本书可分多次逐章处理，结果各自保存到 `outputs/`。默认“PDF 复制文本：修复折行与分段”先合并排版折行，再让 AI 从完整句子/引语单元之间选择边界；整篇粘成一行也能分段。原有空行、明确标题仍保留。长文章按最多 80 个单元、约 12000 字符的窗口处理（最多 12 批，相邻批共享边界上下文）。AI 漏分或不可用时，超过 180 词或 1200 字符的段落会在完整单元之间补充分段，并提示检查；单个超长句或完整引语不强行截断。“保留现有换行与段落”模式不进行 AI 分段，发现超长段会提示切换模式。AI 仅返回边界编号，程序不接受改写全文。PDF 复制丢失的版面信息无法保证全部恢复，请检查对话及标题边界。

## 快速开始

### 1. 配置 API Key

在项目目录创建 `.env` 文件（已列入 `.gitignore`，不会上传）：

```env
DEEPSEEK_API_KEY=sk-你的DeepSeek密钥
DEEPSEEK_MODEL=deepseek-chat
PORT=3456
```

DeepSeek API Key 在 [platform.deepseek.com](https://platform.deepseek.com) 获取。

### 2. 安装依赖（仅首次）

```bash
npm install
```

### 3. 启动

**方式一：双击 `start.bat`**（推荐）

从 BAT 所在目录启动，固定打开 `http://127.0.0.1:3456/`。重复启动复用当前后台和已连接的阅读页面。代码更新后，启动器在后台空闲时更新服务，原标签页自动重新连接；分析期间提示先完成当前任务。无需重新上传已经保存的 EPUB。

**方式二：命令行**

```bash
npm start        # 启动服务
npm run dev      # 开发模式（文件改动自动重启）
```

浏览器打开 `http://localhost:3456`，展开输入区，粘贴文章，先「整理分段并预览」，检查后「确认分段并分析」。

### 4. 本地 PlantUML 渲染

图形仅由本机 Java 和 PlantUML JAR 生成，优先 SVG，失败时尝试本机 PNG。无需启动 Docker，不再回退到在线图形服务。DeepSeek 分段和语法分析仍需联网。

自动查找当前用户 VS Code / VS Code Insiders 的 `jebbs.plantuml-*` 扩展内 `plantuml.jar`，Java 使用已有 `JAVA_HOME` 或 PATH。其他电脑可通过环境变量 `PLANTUML_JAR` 指向已有 JAR。需在运行电脑上准备 Java 和 PlantUML；它们不随源码包分发。

每次 Java 调用启用 SANDBOX、30 秒超时、256 MiB 堆上限及 20 MiB 输出限制；SVG 作为图片嵌入页面。运行 `npm test` 验证，包括真实本机 Java 的默认渲染集成测试，因此测试环境也需要上述工具。

## 界面说明

当前界面由原文、中文译文、语法结构图三栏组成，可调整栏宽、折叠输入区，并把结构图放到独立窗口。点击原文或译文定位对应结构图。

## 项目结构

```
services/              ← 后端服务模块
├── deepseek.js        ← DeepSeek API 调用（含重试、超时）
├── paragraphSplitter.js ← AI 语义段落重排
├── epubParser.js      ← EPUB 解压、目录（nav/NCX）与章节正文提取
├── textSplitter.js    ← 保护称谓、缩写、引号的分句与原文位置
├── plantumlCode.js    ← PlantUML 代码修正（换行、纠错）
├── plantumlRenderer.js ← 本机 Java → SVG / PNG
├── htmlBuilder.js     ← 完整离线阅读 HTML 拼装
└── resultPersistence.js ← 时间戳命名与原子写入 `outputs/`

public/                ← 前端（纯 HTML/CSS/JS，零框架）
├── index.html         ← 页面结构
├── style.css          ← 样式
├── app.js             ← 分段预览、SSE、双栏渲染、联动高亮
├── studyShared.js     ← 在线与离线共用的原文定位
└── diagramViewer.js   ← 离线图页缩放与拖动

server.js              ← Express 服务入口
start.bat              ← 一键启动脚本（Windows）
outputs/               ← 每次生成的永久 HTML 结果（不提交 Git）
```

## 技术栈

| 层 | 技术 |
|---|---|
| 后端 | Node.js + Express |
| 实时推送 | SSE (Server-Sent Events) |
| AI | DeepSeek API（deepseek-chat） |
| 思维导图 | 本机 Java + PlantUML，SVG 优先 |
| 前端 | 原生 HTML/CSS/JS，零 npm 前端依赖 |
| 文本分句 | 确定性规则扫描，保留原文区间 |
| 滚动联动 | `IntersectionObserver` |

## 工作原理

```
输入文本（可能有 PDF 假换行）
    │
    ▼
paragraphSplitter: AI 语义分段（修复假换行）
    │
    ▼
textSplitter: 真段落切分 + 缩写/引号保护分句
    │
    ▼
  ┌─ 段落1标题 ─────────────────────┐
  │  句子1 → DeepSeek → PlantUML码  │
  │        → 本地SVG → 卡片HTML    │
  │  句子2 → DeepSeek → ...         │
  ├─ 段落2标题 ─────────────────────┤
  │  句子3 → ...                     │
  └─────────────────────────────────┘
    │
    ▼
三栏阅读: sections[] 驱动 DOM 构建
完整HTML: 先写入 outputs/，再通知浏览器完成
```

## 版本

### 生词库

双击英文词默认打开独立浏览器查词窗口，可拖到空余位置或另一屏幕，主文章能继续阅读；后续双击复用该窗口，关闭后可重开。浏览器可能需要允许此页面弹窗，阻止时回退页内查词。新保存的 HTML 停服后也可用独立窗口阅读缓存。窗口不强制置顶；重启程序并刷新页面才能使用新版，已有旧 HTML 不会自动改写。

欧路词典双复制：本机程序运行时，双击原文或释义中的英文词会把当前词复制到剪贴板，发送两次真实 Ctrl+C，使用欧路已有的快捷搜索设置；不会修改欧路配置。此操作覆盖剪贴板，需浏览器在前台；前台切换后取消按键。回退、同步词库和未连接程序的离线阅读不发送按键。不安装辅助服务或依赖。

查词弹窗可拖动右下角调整宽高。美式音标及朗读按钮放在每个词性后；打开新词时自动用浏览器 en-US 语音朗读一次。旧缓存缺少词性读音或相关词时，在线打开当前词会自动按需补齐，重复查看优先缓存，不批量更新词库；离线保留已有解释。不同词性的实际发音受本机语音引擎影响。没有可靠反义词时允许为空，不强行生成。

单词详情的“近义词”“反义词”“同词根／词缀相近词”默认展开，可分别收起。双击英文释义、例句或相关词中的单词，可在同一个弹窗继续查词；“返回上一词”恢复上一词、展开状态及滚动位置。查看不会自动收录，详情页仍可手动加入生词库。相关词随当前单词同一次查询生成，重复查询和回退优先缓存；旧释义缺少相关词时，仅在线打开当前词时自动补齐，不批量更新词库。模型生成的词源和词义关联可能存在错误。

在英文原文或 EPUB 原版中双击一个英文单词，直接打开查词详情，不再显示选词操作条。查词详情提供“加入生词库”，已收录词提供“移出生词库”，本次新增收录还可在详情内“撤销本次收录”。查看释义无需收录，移出后取消原文标色；新增收录还可用提示中的“撤销”。查看释义详情也提供“加入生词库”，沿用已查解释并保留原句；收录后显示“移出生词库”。右侧结构图标题栏的“生词库”按钮可打开全部单词、搜索并查看按词性分组的英文释义、美式音标、例句与收录原句，以及“美式朗读”。

数据永久保存在 `data/vocabulary.sqlite`，使用 Node.js 内置 SQLite（需 Node.js 22.13 或更新版本），不需要另装数据库服务。备份时先停止程序，再复制整个 `data/` 目录。词义和美式 IPA 音标调用现有 DeepSeek 接口，沿用当前 API Key 和模型，通用词义仅发送选中的词。“Meaning and role”另外按需发送当前词与所在的一句文字，返回英文词义、词性及语法作用；同词不同句分别缓存，不批量发送文章，超 2000 字符的句子不自动查询。已收录词最多保存八条原句解释，随新生成的 HTML 离线读取。生成结果缓存后无需重复调用；网络或生成失败仍保留收录，稍后可点击“生成 DeepSeek 释义”。解释由 DeepSeek 生成；美式朗读使用本机浏览器 en-US 语音包，不下载第三方词典录音。

普通拖选不调用模型；双击查词时只查询该单词，缓存优先。已收录词的释义保存在 SQLite；只查看、未收录的词使用本次程序运行的临时缓存（最多32词），不会批量扫描整篇文章生成释义。重复或同时查询同一个词复用缓存/正在执行的请求。移出仅取消词库成员身份，保留已有释义缓存，重新收录无需再次生成。

新生成的文章自动用淡黄色标记已收录词及常见变形，忽略大小写；例如 `incantation` 和 `incantations` 关联同一条记录，`incantational` 等派生词不混入。根据已有词性生成复数、动词变化和常见比较级，并支持本地常见不规则表、释义明确指出的原形，以及正常查词同一次返回的 inflections；不为整篇文章追加批量模型请求。选中变形可查看原词释义，移出原词取消相关标色；如果两个拼写分别已收录，优先对应精确拼写。已打开页面可用“同步本机词库”更新。保存 HTML 带词库快照，离线打开不主动联网；新增、撤销、生成释义和同步需要程序运行。离线朗读需要本机美式英语语音包。启动器更换端口后，请打开新生成的页面连接词库。

导出文件包含个人词库快照及本机词库访问凭据，按个人学习文件保管。词库数据库、录音缓存和导出文件均忽略 Git，程序不自动清理。原有 HTML 继续可阅读；新功能出现在更新后生成的页面。

### 三栏、双屏和阅读空间

EPUB 默认显示原书排版，中间独立显示对应中文译文，右边显示结构图；TXT/PDF 使用提取原文。点击原文或译文按同一句编号联动，原文不会再重复显示一份英文对照。直接拖动两条栏边界可调整三栏宽度，也可聚焦边界后用左右方向键调整；双屏主窗口的原文和译文边界同样可拖动。

点击英文句子时，译文按该句在英文可视阅读区中的相对高度定位，靠上、居中或靠下时保持相近位置，英文阅读位置保持不动；点击译文则反向定位英文。计算会避开栏头和工具栏，EPUB 原版、提取原文、双屏及新保存的离线页面共用此逻辑。首尾句受各栏实际可滚动空间限制，尽量对齐。

点击“双屏阅读”或按 Ctrl+Alt+D，打开单独的结构图窗口，把主窗口和图窗分别拖到两个屏幕。图窗支持上一句/下一句、适配整图、100%、滚轮缩放和拖动；两窗口联动，关闭图窗恢复三栏。浏览器阻止弹窗时，请允许本页弹窗后再点击。无需授权程序自动控制显示器。

“折叠工具栏”隐藏顶部输入、目录、预览、进度与底部工具区，保留阅读空间和恢复按钮；点击“恢复工具栏”还原。保存 HTML 离线也支持调整栏宽、折叠和双屏。

分析校验会保留原句并容忍智能引号、破折号及空白排版差异；真正漏词/改写仍拒绝绘图，并自动请求一次针对性校正。校正后仍失败会显示具体类别，不会用错误内容强行绘图。该修复用于新生成结果，原有已保存页面不被自动覆盖。
