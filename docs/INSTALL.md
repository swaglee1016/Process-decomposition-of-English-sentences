# 安装与开始使用

适用：Windows 10 / 11 x64。首次准备需要联网。下载安装程序后，不需要自己安装 Node.js、Java 或执行命令。

## 第一次使用

1. 双击 `SentenceProcess-Setup.exe`，点击 **检查准备情况**。
2. 查看组件清单。已有且可用的组件直接使用；缺少时会显示版本、大小与来源。点击 **同意下载并安装**。
3. 等待下载、校验和准备完成。页面底部显示正在处理的组件与进度。中断后可以重新运行，已完成且校验通过的下载会复用。
4. 输入你自己的 DeepSeek API Key。可通过向导里的控制台链接获取。保留“创建桌面快捷方式”选项，点击 **保存并完成安装**。
5. 看到 **程序已安装完成** 后，点击 **立即打开**。阅读器会在默认浏览器中打开。

以后双击桌面的 **英文精读**，或安装目录里的 `Reader.exe` 即可。阅读程序仍使用浏览器界面，无需另装浏览器框架。

## 下载什么，保存在哪里

| 组件 | 用途 | 缺少时下载的固定版本 |
|---|---|---|
| Node.js | 运行阅读程序与本地词库 | 22.23.4，约 34 MB |
| Java / Eclipse Temurin | 运行本机绘图工具 | 17.0.21+9 JRE，约 42 MB |
| PlantUML | 生成语法结构图 | 1.2026.9 MIT，约 17 MB |

全部缺少时约 93 MB（按 1024 进制取整）；已有可用组件会复用。Node.js 来自 nodejs.org，Java 和 PlantUML 来自各自项目的 GitHub Release。固定清单和校验值见源码中的 `installer/components.json`。

默认安装到当前用户本地应用目录中的 `SentenceProcess`。可以在欢迎页选择另一个空目录。安装器不会修改系统 PATH 或覆盖电脑上现有运行环境。

- `Reader.exe`：以后打开应用的入口，也支持 `--settings` 打开配置向导。
- `app/`：阅读程序与所需 npm 依赖。
- `runtime/`：本应用下载的运行组件。
- `cache/`：已下载文件及可能保留的中断文件。
- `settings/`：当前用户加密的 API Key 和本机运行配置。
- `app/data/`：书籍、阅读进度和生词库。
- `app/outputs/`：完整 HTML 精读笔记。

程序不会自动删除旧书、笔记和中断下载文件。备份个人内容时，停止阅读服务后复制 `app/data/` 和 `app/outputs/`；密钥加密绑定当前 Windows 用户，换电脑应重新填写。

## API Key 与费用

Key 在当前 Windows 用户下加密保存，不写入源码、安装包、日志或启动命令。安装过程只检查输入格式，不发送文章、不调用 AI；它不能证明 Key 的余额和有效性。

实际分析、翻译、查词以及无目录 EPUB 的自动目录生成，会把相关内容发送到 DeepSeek，并可能产生 API 用量。不要公开分享个人生成的学习页，其中可能含词库快照及本机访问凭据。

修改 Key：重新运行原安装程序并选择原安装目录，或运行安装目录中的 `Reader.exe --settings`。如果分析正在进行，请先等待完成，再修改配置。

## 常见情况

- **下载失败**：检查网络是否能够访问页面显示的官方来源，然后重试。安装器不会自动切换到不明镜像。
- **校验失败**：不执行该文件，重新下载；已存在的个人内容保留。
- **目录已有其他文件**：选择专用空文件夹。首版不自动覆盖不同版本，也不会自动迁移开发目录里的个人数据。
- **桌面已有同名入口**：取消创建快捷方式即可保留原入口；以后从安装目录打开 `Reader.exe`。
- **地址被占用**：阅读器使用 `127.0.0.1:3456`。先退出另一份旧阅读器，再启动；安装器不会结束其他程序。
- **修改密钥后仍提示无效**：检查粘贴内容，并在 DeepSeek 控制台确认密钥状态和账户情况。
- **Windows 显示未知发布者**：当前安装包未做数字签名。核对文件来源和随附 SHA-256；不要关闭系统安全功能。安装包通过 GitHub Releases 提供下载。

## 开发者构建

源码中的 `installer/build.ps1` 使用 Windows 自带的 .NET Framework C# 编译器创建 EXE，并在全新 `outputs/installer-build-*` 中准备生产依赖。构建电脑需要 Node/npm 和联网条件；最终用户不需要执行 npm。

构建命令：`powershell -File installer/build.ps1`。每次使用新的构建目录，保留已有产物。安装包只包含显式选定的程序文件和生产依赖，不包含 `.env`、个人数据或历史笔记。

详细阅读功能见 [使用指南](USER-GUIDE.md)。本机真实下载与安装验证结果另见项目验收记录；隔离目录验收不等同于全部 Windows 版本的干净虚拟机测试。
